Question 4 of 6 · Microsoft AI apps and services
A CIO asks: 'What is the fundamental difference in target audience between Microsoft Copilot Studio and Microsoft Foundry when building custom AI solutions?' Which statement correctly describes this difference?
Copilot Studio targets business users and IT pros through a low-code agent-building experience grounded in Microsoft 365/Graph data, while Foundry is a pro-code platform for developers who need a model catalog, custom orchestration, and enterprise-grade app development.
Question 5 of 6 · Microsoft AI apps and services
A CISO wants to adopt Microsoft Security Copilot but is concerned about unpredictable costs because usage varies week to week across the SOC team investigating incidents. Which statement correctly describes how Microsoft Security Copilot is priced?
Security Copilot uses a consumption-based model measured in Security Compute Units (SCUs), letting organizations provision capacity and scale it up or down to match fluctuating SOC workload, directly addressing the CISO's cost-predictability concern.
