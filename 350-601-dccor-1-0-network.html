Question 1 of 6 · 1.0 Network
A pair of Nexus 9000 switches form a vPC domain and provide the default gateway via HSRP to a directly attached load balancer. The load balancer occasionally sends return traffic using the router MAC address of the vPC peer switch instead of the local switch's MAC, and this traffic is intermittently dropped. Which feature should be enabled to resolve this without redesigning the topology?
peer-gateway allows each vPC peer to locally forward (rather than drop) packets destined to the peer's router MAC address, avoiding the need to cross the peer-link. This is the documented fix for asymmetric-routing devices such as firewalls and load balancers that cache the peer's MAC.
Question 2 of 6 · 1.0 Network
In a VXLAN BGP EVPN fabric, an external subnet that sits behind a non-VXLAN router is redistributed into the fabric so border leaf switches can advertise reachability to it. Which EVPN route type carries this IP prefix reachability information across the fabric?
Type-5 routes advertise IP prefixes (not tied to a specific MAC) that are not directly attached hosts in the fabric, typically originated at border leafs for externally learned subnets and redistributed into BGP EVPN.
Question 3 of 6 · 1.0 Network
An OTV site has two edge devices providing multi-homing, extending VLANs 10 and 20 over the overlay. No AED priority has been manually configured. Which statement correctly describes AED assignment for these VLANs?
By default, without configured priorities, OTV alternates AED ownership per VLAN between the two edge devices in a site (commonly split by odd/even VLAN ID), guaranteeing only one AED forwards traffic for a given VLAN and preventing duplicate forwarding/loops.
Question 4 of 6 · 1.0 Network
An ACI administrator configures an L3Out using OSPF to an external router and applies a contract between an application EPG and the L3Out's external EPG. Routes from the external network are learned correctly, but the internal bridge domain subnet is not being advertised out via OSPF despite the contract being in place. What is the most likely cause?
For a BD subnet to be redistributed out an L3Out, its subnet scope must include 'Advertised Externally.' Without this flag, the subnet is never eligible for external route advertisement regardless of contract state.
Question 5 of 6 · 1.0 Network
Two EPGs requiring HTTPS communication reside in different VRFs within the same tenant. A contract with an HTTPS filter is provided and consumed between them, but traffic is still blocked by the implicit deny. The contract's scope is currently set to VRF. What must be changed to allow this communication?
Contract scope 'Tenant' permits communication between EPGs in different VRFs as long as they are within the same tenant, which is exactly the requirement here.
Question 6 of 6 · 1.0 Network
An ACI Multi-Site deployment interconnects two fabrics over a Layer 3 WAN (ISN) that does not support multicast. How does Nexus Dashboard Orchestrator ensure BUM (broadcast, unknown unicast, and multicast) traffic is still delivered between sites for a stretched bridge domain?
ACI Multi-Site specifically avoids requiring multicast support in the ISN by using head-end/ingress replication: the source spine replicates BUM traffic as individual unicast VXLAN-encapsulated packets destined to the remote site's spine anycast TEP addresses.
