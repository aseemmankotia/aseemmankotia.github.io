Question 1 of 12 · vSphere Architecture and vCenter/ESXi Foundations
An architect is sizing a new vCenter Server Appliance deployment for an environment that currently has 350 ESXi hosts and is expected to grow to 4,500 powered-on VMs within the year. Which deployment size BEST meets these requirements while avoiding unnecessary resource overhead?
Large supports up to 1,000 hosts and 10,000 VMs, which comfortably covers 350 hosts and, critically, the 4,500 VM count that exceeds Medium's 4,000 VM ceiling.
Question 2 of 12 · Virtual Networking
A vSphere administrator manages a vSphere Distributed Switch (vDS) with four physical uplinks. Several port groups experience uneven traffic patterns throughout the day, and the administrator wants traffic to be dynamically redistributed across uplinks based on actual physical NIC utilization rather than a static hash. Which NIC teaming and failover policy should be configured?
Route based on physical NIC load (Load Based Teaming, LBT) is available only on a vDS and dynamically moves flows between uplinks when one uplink's utilization exceeds 75% for 30 seconds, achieving true load-aware distribution.
Question 3 of 12 · Storage
A company's vSphere 8 environment uses an active-active Fibre Channel array that supports ALUA. The storage team wants ESXi hosts to distribute I/O evenly across all available optimized paths to maximize throughput. Which Path Selection Policy should be configured on the affected datastores?
Round Robin cycles I/O across all active optimized paths in a configurable batch, providing load distribution across paths on ALUA-capable active-active arrays.
Question 4 of 12 · Virtual Machine Management
A VM in vCenter Server shows no snapshots listed in the Snapshot Manager, but its datastore folder contains multiple delta VMDK files and the VM's disk usage keeps growing. Which action should the administrator take to resolve this without disrupting the VM's running state?
When snapshot delta files remain on disk but the Snapshot Manager shows none (often after a failed snapshot removal), vSphere flags the VM as needing consolidation. The Consolidate operation merges orphaned delta disks into the base disk while the VM continues running, without needing to recreate a snapshot first.
Question 5 of 12 · Resource Management and Availability
A resource pool named RP-Finance has a memory reservation of 16 GB with 'Reservation Not Expandable' selected. VMs inside RP-Finance are powered on and consume the full 16 GB. An administrator attempts to power on an additional VM inside RP-Finance that requires an additional 4 GB reservation, but there is 32 GB of unreserved memory available at the cluster level. What happens?
When 'Expandable Reservation' is disabled, a resource pool cannot borrow unreserved resources from its parent (or the cluster) even if capacity exists above it. Admission control for the VM's power-on evaluates only against the resource pool's own defined reservation, so the operation fails with an insufficient resources error.
Question 6 of 12 · Security, Lifecycle, and Monitoring
An administrator manages a cluster with vSphere Lifecycle Manager (vLCM) using a single image. After adding a new host with a network adapter from a different vendor, the cluster image compliance check reports the new host as non-compliant due to a missing driver. Which action should the administrator take to bring the host into compliance?
vLCM cluster images support vendor add-ons that bundle firmware and drivers for specific hardware. Adding the correct add-on to the image and remediating ensures the host receives the required driver while keeping the entire cluster on a single, consistent image.
Question 7 of 12 · vSphere Architecture and vCenter/ESXi Foundations
Which vCenter Server Appliance interface is used to configure appliance-level settings such as NTP time sync, network configuration, and applying appliance patches?
VAMI, accessed at https://<vcsa-fqdn-or-ip>:5480, is the dedicated appliance management portal for NTP, network settings, disk space monitoring, backup, and patching of the vCenter Server Appliance itself.
Question 8 of 12 · Virtual Networking
An administrator must guarantee that vMotion traffic receives a minimum amount of bandwidth on shared 10GbE uplinks during periods of network contention, without permanently limiting other traffic types when the network is idle. Which vSphere Distributed Switch feature should be used?
Network I/O Control (NIOC) version 3 on a vDS allows administrators to set bandwidth reservations, shares, and limits per system traffic type (such as vMotion). A reservation guarantees minimum bandwidth only during contention, while allowing full link usage when the network is not congested.
Question 9 of 12 · Storage
An organization is designing a new all-flash vSAN 8 cluster and wants the simplest per-host storage architecture with a single pool of NVMe devices, no separate cache and capacity tiers, and improved space efficiency. Which vSAN architecture should they select?
vSAN ESA uses a single storage pool per host built from high-performance NVMe/flash devices, eliminating the separate cache/capacity tier split required by OSA and providing better space efficiency through compression and native snapshots.
Question 10 of 12 · Virtual Machine Management
An organization has a central vCenter Server that maintains master copies of VM templates and ISO images. Multiple remote sites, each with their own vCenter Server and limited WAN bandwidth, need periodic access to updated templates. Which vSphere feature BEST meets this requirement?
A published content library at the central site combined with subscribed libraries at remote sites allows scheduled or on-demand synchronization, controlling WAN bandwidth usage and ensuring remote sites have updated templates and ISOs without manual copying.
Question 11 of 12 · Resource Management and Availability
A cluster hosts a mixed workload where administrators want vCenter to automatically calculate placement and migration recommendations for virtual machines, but a compliance policy requires that a human explicitly approve every vMotion before it executes. Which DRS automation level meets this requirement?
Partially Automated mode has DRS automatically place VMs at power-on, but all load-balancing migration recommendations after that must be manually approved by an administrator before they execute — matching the requirement that placement is automatic but every vMotion still needs explicit human approval.
Question 12 of 12 · Security, Lifecycle, and Monitoring
A virtual machine exhibits sluggish performance despite low CPU utilization reported at the host level. Using esxtop, the administrator observes a %RDY value of 15 for one of the VM's vCPUs. What does this metric indicate?
%RDY represents the percentage of time a vCPU was ready to run but had to wait in the queue for a physical CPU to be scheduled. A value above roughly 10% is generally considered a sign of CPU contention on the host.
