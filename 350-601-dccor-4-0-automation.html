Question 1 of 6 · 4.0 Automation
A DevOps engineer is writing a Python script that must send multiple CLI commands (a mix of 'show' and configuration commands) to a Nexus 9000 switch in a single HTTP POST for both efficiency and atomic execution. The script uses NX-API. Which approach correctly achieves this?
NX-API's JSON-RPC 2.0 transport natively supports batching multiple cli_show/cli_conf method calls as an array in one HTTP POST to the /ins endpoint, giving both efficiency and single-transaction execution — this is the documented NX-API batching pattern tested on the exam.
Question 2 of 6 · 4.0 Automation
An automation team needs to add a subnet (e.g., 10.1.1.1/24) under an existing bridge domain in a Cisco ACI fabric using Ansible. Which module from the cisco.aci collection should be used?
cisco.aci.aci_bd_subnet is the specific module that manages the fvSubnet object under a bridge domain (BD), matching the required task exactly.
Question 3 of 6 · 4.0 Automation
After entering 'feature nxapi' on a Nexus 9000 switch with no further HTTP-related configuration, which TCP port is used by default for NX-API management access?
NX-API defaults to HTTPS on TCP 443 once the feature is enabled; HTTP on port 80 must be explicitly enabled separately if desired.
Question 4 of 6 · 4.0 Automation
A UCS administrator needs to programmatically instantiate 50 new service profiles from a single existing service profile template in one XML API call. Which UCS Manager XML API method is designed for this exact operation?
lsInstantiateNTemplate is the UCS Manager XML API method specifically designed to create N service profiles from a template in a single call, which is required for bulk provisioning like the 50-profile scenario described.
Question 5 of 6 · 4.0 Automation
An engineer needs a configuration management framework where a persistent agent runs on managed nodes, periodically pulls declarative manifests from a central master server, and enforces idempotent resource state using a domain-specific language. Which automation tool matches this description as used in DCCOR-scoped data center automation?
Puppet uses an agent/master architecture where a Ruby-based agent on each node periodically pulls manifests written in Puppet's declarative DSL from a Puppet master and enforces the desired state — this agent-based, pull-model behavior is the key exam differentiator versus agentless tools.
Question 6 of 6 · 4.0 Automation
Which statement correctly contrasts the data encoding supported by NX-API versus the Cisco UCS Manager XML API?
NX-API supports JSON-RPC 2.0 as its primary structured transport (with XML also available for CLI-style requests), while the UCS Manager API is fundamentally XML-based, using method calls like configConfMo and configResolveDn with XML request/response bodies — it does not offer a native JSON encoding.
