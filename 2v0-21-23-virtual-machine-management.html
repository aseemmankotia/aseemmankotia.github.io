Question 1 of 6 · Virtual Machine Management
An administrator manages a master VM template in a Content Library and wants to make configuration changes while preserving the ability to roll back to the prior version if the update introduces a problem, using the built-in versioning capability of VM Templates in Content Libraries. Which workflow should be used?
Since vSphere 7, VM Templates in Content Libraries support native version control via check-out/check-in. Checking out creates an editable VM copy; checking it back in commits the changes as a new version while retaining prior versions for rollback.
Question 2 of 6 · Virtual Machine Management
An administrator needs to migrate a powered-on VM using cross vCenter vMotion from vCenter Server A to vCenter Server B. The two vCenter Server instances are registered in different SSO domains and are not linked. Which method allows this migration to complete?
Cross vCenter vMotion is supported across different SSO domains, but the drag-and-drop UI workflow requires Enhanced Linked Mode. When the vCenter Servers are not linked, the API-based approach (e.g., PowerCLI Move-VM with credentials for both vCenter Servers) is required to perform the migration.
Question 3 of 6 · Virtual Machine Management
What is the maximum virtual machine hardware (compatibility) version supported when a VM is running on an ESXi 8.0 host?
ESXi 8.0 introduces and supports up to virtual hardware version 20, which enables new features such as expanded vGPU and device support. VMs must be upgraded to this version to use ESXi 8.0-specific hardware capabilities.
Question 4 of 6 · Virtual Machine Management
A VM displays a configuration issue in vCenter stating that disk consolidation is needed, after a third-party backup job failed to remove snapshot delta files correctly. Delta disks have been accumulating for several days. Which action resolves this without causing data loss?
The Consolidate action merges orphaned delta disks back into the base disk while the VM remains in its current running state, safely resolving the 'needs consolidation' condition without losing changes made after the failed snapshot removal.
Question 5 of 6 · Virtual Machine Management
A VM includes a Raw Device Mapping (RDM) configured in physical compatibility mode, used to support an MSCS cluster across physical hosts. The administrator performs a Storage vMotion on this VM to move it to a new datastore. What happens to the RDM's underlying LUN during this operation?
For RDMs in physical compatibility mode, Storage vMotion migrates only the small mapping file that points to the LUN; the raw LUN itself and its data remain on the original physical storage device, since physical mode RDMs bypass the VMkernel's virtualization layer.
Question 6 of 6 · Virtual Machine Management
An administrator attempts to export a VM protected by VM Encryption as an OVF template for archival purposes. What must be done before this export can succeed?
vSphere does not support exporting an OVF template from a VM that has VM Encryption enabled. The VM must first be decrypted (its disks and configuration data returned to unencrypted state) before the OVF export operation will succeed.
