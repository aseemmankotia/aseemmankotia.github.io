Question 1 of 6 · vSphere Architecture and vCenter/ESXi Foundations
A company deploys vCenter Server High Availability (VCHA) for its production vCenter Server Appliance using the automatic configuration wizard. Which statement correctly describes the role of the Witness node in this architecture?
In VCHA, the Witness node is a minimal-footprint appliance whose only job is to provide quorum (tie-breaker) between the Active and Passive nodes to avoid split-brain scenarios. It does not hold a copy of the vCenter database.
Question 2 of 6 · vSphere Architecture and vCenter/ESXi Foundations
An administrator wants to use vSphere Quick Boot to speed up host remediation during a vSphere Lifecycle Manager (vLCM) remediation task on an ESXi 8.0 host that has a TPM 2.0 chip installed and Secure Boot enabled. What happens regarding Quick Boot on this host?
VMware documents that Quick Boot, which skips the physical hardware BIOS/UEFI POST, is not compatible with hosts that have a physical TPM 2.0 chip because the TPM's platform configuration registers (PCRs) must be re-measured during a full hardware boot to maintain a valid trust chain; vLCM automatically falls back to a full reboot on such hosts.
Question 3 of 6 · vSphere Architecture and vCenter/ESXi Foundations
An administrator is deploying a new vCenter Server Appliance to manage an environment that will grow to 2,000 ESXi hosts and 25,000 powered-on virtual machines. During the stage 1 deployment wizard, which deployment size should be selected to meet this capacity?
The X-Large VCSA deployment size supports up to 2,000 hosts and 35,000 powered-on VMs, which is the only sizing tier that accommodates both the 2,000-host and 25,000-VM requirements.
Question 4 of 6 · vSphere Architecture and vCenter/ESXi Foundations
Two existing vCenter Server 8.0 Appliances were originally deployed with separate vCenter Single Sign-On domains. The administrator now wants to join them using Enhanced Linked Mode so both appear in a single inventory view. Which approach correctly achieves this without a full redeployment of either appliance?
Since vSphere 6.5/6.7's PSC-embedded architecture (carried into vSphere 7/8), Enhanced Linked Mode requires all participating vCenter Servers to share the same SSO domain. The cmsso-util move command lets you move an existing vCenter Server Appliance into another vCenter's SSO domain without redeploying it from scratch.
Question 5 of 6 · vSphere Architecture and vCenter/ESXi Foundations
An ESXi 8.0 host has UEFI Secure Boot enabled and also contains a TPM 2.0 chip. What capability does this combination specifically enable that is visible from vCenter Server?
When a host has both UEFI Secure Boot enabled and a physical TPM 2.0 chip, ESXi can measure and seal boot component hashes into the TPM, and vCenter Server performs remote attestation, displaying the host's Secure Boot/attestation status on the host summary/monitor view as Passed or Failed.
Question 6 of 6 · vSphere Architecture and vCenter/ESXi Foundations
An administrator is performing a fully unattended, scripted installation of ESXi 8.0 via PXE boot, and needs the installer to retrieve its kickstart configuration file from an HTTP server at 192.168.1.10. Which boot option correctly instructs the ESXi installer to load the kickstart file from that location?
The ESXi installer boot option 'ks=' specifies the URL or path where the kickstart (ks.cfg) configuration file is located, supporting protocols such as http, https, ftp, nfs, usb, and cdrom.
