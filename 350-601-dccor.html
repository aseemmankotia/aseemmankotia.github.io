Question 1 of 12 · 1.0 Network
In a Cisco NX-OS vPC domain, the vPC peer-link fails completely, but the separate peer-keepalive link remains up and reachable. What action does the vPC secondary switch take?
Because the peer-keepalive is still up, the secondary switch knows the primary is alive. Since CFS synchronization can no longer occur over the failed peer-link, the secondary suspends its local vPC member ports to avoid duplicate frames and a forwarding loop, while the primary keeps forwarding.
Question 2 of 12 · 2.0 Compute
A UCS administrator manages 40 service profiles derived from a single service profile template. Management requires that any future BIOS or vNIC changes made to the template be applied automatically to all derived profiles without manual re-association. Which action satisfies this requirement?
An 'Updating Template' propagates any configuration change made to the template to all service profiles bound to it, keeping them in sync automatically. An 'Initial Template' only applies its configuration at the moment a profile is created and does not propagate later changes.
Question 3 of 12 · 3.0 Storage Network
A large enterprise fabric already has 200 domain IDs allocated across two core directors. The company is deploying 40 new edge switches to connect additional hosts and wants to add them without consuming additional domain IDs or requiring interoperability mode changes on the core. Which Cisco MDS feature should be used on the new edge switches?
NPV mode makes the edge switch log in as an end-node device (proxy) rather than a full fabric switch, so it does not consume a domain ID and requires no interop mode change on the core.
Question 4 of 12 · 4.0 Automation
A network engineer must push identical VLAN configuration changes to 50 Nexus 9000 switches running NX-OS and ensure the task is safe to re-run without causing configuration drift or duplicate entries. Which automation approach BEST meets this requirement?
The nxos_config Ansible module is purpose-built for idempotent NX-OS configuration management; it compares the running config to the desired state and only applies the delta, so re-running the playbook produces no unintended changes.
Question 5 of 12 · 5.0 Security
A network administrator needs remote TACACS+ users to be automatically assigned a custom NX-OS role called 'read-only' upon login, without configuring local user accounts on each switch. Which configuration achieves this?
NX-OS RBAC integrates with TACACS+ by having the AAA server return a cisco-av-pair (shell:roles="rolename") that maps the authenticated user to a role that must already exist locally on the switch. This allows centralized role assignment without creating local accounts.
Question 6 of 12 · 1.0 Network
A company operates three physical data centers connected over a routed IP core. They must extend select Layer 2 VLANs between sites while preventing STP BPDUs from crossing the interconnect, and they require a control-plane protocol that advertises MAC reachability instead of relying purely on flood-and-learn. Which Cisco technology BEST meets these DCI requirements?
OTV is Cisco's purpose-built DCI overlay. It uses IS-IS as a control plane to advertise MAC reachability between sites, natively drops STP BPDUs at the edge device boundary (site independence), and provides failure isolation across the transport-agnostic IP core.
Question 7 of 12 · 2.0 Compute
A Cisco UCS C-series server integrated with UCS Manager via Cisco Nexus 2232PP Fabric Extenders fails to appear in the Equipment tab for discovery. Physical cabling and CIMC connectivity have been verified as correct. What should the administrator check first?
Fabric interconnect ports facing the FEX (or C-series server directly) must be explicitly configured as Server Ports in UCS Manager before discovery can occur. Ports default to unconfigured/monitor state and will not initiate discovery until set correctly.
Question 8 of 12 · 3.0 Storage Network
A virtualization host runs eight VMs, each requiring its own persistent Fibre Channel WWN for independent zoning and LUN masking, but the host has only a single physical HBA port connected to the fabric. Which Fibre Channel feature allows that single physical port to log in with multiple virtual N_Port IDs, one per VM?
NPIV allows a single physical HBA port to register multiple FCIDs/WWNs with the fabric, one per virtual machine, enabling independent zoning and LUN masking per VM.
Question 9 of 12 · 4.0 Automation
An automation engineer wants a Python script to query the operational state of a Nexus 9000 switch and receive the output of 'show interface status' as structured, machine-parsable data instead of raw CLI text. Which method should be used?
NX-API exposes NX-OS CLI commands over HTTP/HTTPS using JSON-RPC (or JSON) message formats, returning show command output as structured JSON that a Python script can parse directly without screen-scraping.
Question 10 of 12 · 5.0 Security
Two EPGs must communicate bidirectionally, but only over TCP port 443. Which combination of ACI security constructs correctly enforces this with the least additional configuration?
A single contract with a subject filter for TCP/443, applied provider/consumer between the EPGs with 'Apply Both Directions' and 'Reverse Filter Ports' enabled, automatically generates the return-traffic rule, giving least-privilege bidirectional access with minimal configuration.
Question 11 of 12 · 1.0 Network
On a Cisco Nexus switch acting as a VXLAN BGP EVPN VTEP, which command under the NVE1 VNI member configuration enables the switch to use BGP EVPN to build the head-end replication list for BUM traffic instead of a multicast underlay?
Under 'member vni <id>' on interface nve1, the command 'ingress-replication protocol bgp' tells the VTEP to derive the ingress-replication peer list dynamically from BGP EVPN Type-3 routes rather than requiring a static peer list or PIM multicast group.
Question 12 of 12 · 2.0 Compute
An administrator is designing service profile templates for a UCS domain and needs vHBAs to receive unique, automatically-assigned Fibre Channel port identifiers without manual configuration on each profile. Which UCS Manager pool should be used?
A WWPN (World Wide Port Name) pool assigns unique Fibre Channel port identifiers to vHBAs, which is required for FC/FCoE fabric login and zoning.
